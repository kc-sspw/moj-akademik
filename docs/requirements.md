# Wymagania — Mój Akademik

## Problem

Do ustalenia z Komisją i interesariuszami. Dostępne materiały nie potwierdzają jeszcze dokładnego problemu, odbiorców ani funkcji produktu.

## Odbiorcy

Do potwierdzenia.

## Zakres potwierdzony

Na tym etapie potwierdzone jest jedynie uruchomienie projektu i koordynacja wdrożenia w kadencji 2026/2027.

## Poza zakresem na tym etapie

Nie zakładamy bez potwierdzenia m.in. systemu zgłoszeń, płatności, rezerwacji, integracji ani konkretnych procesów administracyjnych.

## Zależności

- wskazanie lidera,
- potwierdzenie problemu i odbiorców,
- uzgodnienie pierwszego ograniczonego etapu,
- decyzje Komisji dotyczące zależności organizacyjnych.

## Kryterium gotowości do implementacji

Implementacja może ruszyć po zapisaniu:
1. problemu,
2. pierwszego zakresu,
3. właściciela/lidera,
4. zależności,
5. mierzalnego kryterium odbioru.

## Otwarte pytania

- Jaki konkretny problem użytkownika rozwiązujemy?
- Kto jest odbiorcą pierwszej wersji?
- Kto podejmuje decyzje produktowe?
- Jaki jest najmniejszy sensowny etap pilotażowy?
