# Decyzje architektoniczne

Istotne decyzje techniczne i produktowo-techniczne zapisujemy jako krótkie ADR-y.

Konwencja nazw:

`ADR-0001-krotki-tytul.md`

Każdy ADR powinien zawierać: kontekst, decyzję, konsekwencje, rozważane alternatywy oraz status.

Na etapie inicjalizacji projektu nie wybrano technologii ani architektury.
