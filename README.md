# Mój Akademik

Projekt Komisji Cyfryzacji SSPW na kadencję 2026/2027.

## Cel

Projekt dotyczy obszaru akademików. Dokładny problem, odbiorcy i funkcje nie są jeszcze potwierdzone w dostępnych materiałach projektowych, dlatego repozytorium nie zakłada funkcjonalności bez wcześniejszej decyzji zespołu.

## Aktualny stan

Etap inicjalizacji projektu i doprecyzowania zakresu.

## Minimalny zakres pierwszego etapu

- zdefiniować problem i odbiorców,
- wskazać lidera projektu,
- wybrać jeden ograniczony pierwszy etap,
- spisać zależności,
- ustalić mierzalne kryterium odbioru.

## Zależności

- decyzja Komisji o zakresie,
- wskazany lider,
- potwierdzone wymagania interesariuszy.

## Następny krok

Uzgodnić problem, lidera, pierwszy ograniczony etap i kryterium odbioru. Następnie zaktualizować [wymagania](docs/requirements.md).
